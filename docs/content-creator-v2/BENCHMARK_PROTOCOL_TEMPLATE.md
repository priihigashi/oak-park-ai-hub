Same input, same target output, same clock.

Do not compare a polished SaaS demo against an unfinished internal prototype. Compare one real task Priscila actually needs.

## First recommended benchmark

Use one OPC job with enough footage to make a 30–60 second process/reveal reel.

Test sequence:

1. Apple Photos/job-site index finds source clips.
2. CapCut creates a fast 9:16 manual reel.
3. Premiere imports same folder and tests semantic search.
4. Descript or Gling tests a talking-head clip if available.
5. Internal Remotion/manual builder or V2 attempt uses the same brief.

## Success threshold

The winning route must reduce Priscila's active thinking and manual searching, not just create more tools to manage.
