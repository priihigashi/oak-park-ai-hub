# Goal do guia Disney

Transformar o roteiro de abril de 2026 em um guia de referência reutilizável para novas visitas.

1. [ ] **Datas arquivadas**. Identificar abril de 2026 como roteiro passado e destacar o calendário oficial para próximas visitas.
2. [ ] **Clima**. Exibir o clima atual de Orlando separado das datas de arquivo e remover a previsão para dias passados.
3. [ ] **Lightning Lane**. Corrigir a janela de compra e separar Multi Pass de Single Pass conforme a Disney.
4. [ ] **Altura**. Corrigir The Barnstormer e remover a alegação de pulseira válida pela viagem inteira.
5. [ ] **Rider Switch**. Revisar a troca de adultos e orientar que o grupo se apresente na entrada da atração.
6. [ ] **Links de refeições**. Corrigir Oga’s Cantina e Mobile Order com os endereços oficiais.
7. [ ] **Acessibilidade**. Dar nomes aos botões de reserva, manter foco visível e criar atalho para o conteúdo.
8. [ ] **Navegação móvel**. Organizar atalhos para parques, comida, logística e calendário acima do roteiro.
9. [ ] **Preços e shows**. Identificar preços impressos como referência de arquivo e associar horários à consulta oficial.
10. [ ] **Roteiro reutilizável**. Criar uma lista de preparação editável por navegador, sem dados familiares no código.

Validação: conferir fontes oficiais, checar links internos e testar os controles no navegador.
