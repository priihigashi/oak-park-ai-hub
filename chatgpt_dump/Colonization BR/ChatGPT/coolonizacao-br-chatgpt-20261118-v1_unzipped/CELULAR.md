# Usar no celular com o Mac desligado

Recomendação para evitar procurar toda vez: manter um projeto do ChatGPT chamado “Reels e Carrosséis” com este guia e a versão desejada como fontes. Projetos preservam arquivos e instruções entre dispositivos. A criação/configuração desse projeto não foi realizada nesta sessão.

Instrução curta para o projeto: “Ao pedir um estilo, leia a versão ChatGPT identificada no índice e suas regras-priih; confirme nome e versão carregados. Preserve o pedido RAW e as versões. Se o arquivo ou conector estiver indisponível, diga qual acesso faltou, sem inventar que carregou.”

A documentação oficial atual distingue skills locais de skills distribuídas em plugins. As primeiras não são prova de disponibilidade no celular; as de plugins são suportadas em Chat e Work na web, desktop e celular. O pacote privado news-priih já existe nesta instalação e inclui BR, mas sua disponibilidade e habilitação no iPhone não foram testadas. Não há motivo para prometer que um comando / vai mostrar as pastas locais.

Caminho simples verificável nesta sessão: arquivo de instruções no Drive, lido pelo conector. Na conversa do celular com Google Drive disponível, abrir o link e pedir leitura da versão exata. Se o conector não estiver disponível no telefone, baixar o arquivo de instruções e anexá-lo ao projeto uma vez. Usar arquivo anexado significa snapshot da versão, não atualização automática. Também é possível adicionar o link Drive como fonte do projeto quando essa opção estiver disponível; a documentação diz que isso não faz sincronização antecipada.

Acesso a texto não comprova execução/render. Não foi feito teste físico no iPhone nem com o Mac desligado. O GitHub privado foi lido pelo conector deste chat; acesso no celular permanece não verificado. As cópias do Drive e GitHub são duráveis, mas não prometem memória global entre produtos.
