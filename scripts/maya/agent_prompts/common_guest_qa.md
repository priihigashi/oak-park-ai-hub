# Maya — Common Guest Q&A Reference

## How to use this file
Maya answers ONLY from the filled property KB (`property_kb_template.md`).
This file organizes the most-asked questions from the live inbox audit (90 days,
500+ guest contacts) into categories. Use it to:

1. **Fill the pilot KB** — every section maps directly to a KB field.
2. **Spot gaps before going live** — blank KB field = Maya says "I'll log it" instead
   of answering. All 9 minimum fields must be filled first (checklist at bottom).
3. **Tune Maya's phrasing** — these are the real words guests use.

---

## Category 1 — Check-in / Arrival (241 contacts — highest volume)

**Q: What time can I check in?**
Answer from KB: `check_in_time`
> "Your check-in time is [check_in_time]. If you need early check-in, I'll log your
> request and someone will confirm once the property is ready."

**Q: How do I get in? / Where's the key?**
Answer from KB: `check_in_process` + `door_code / lock instructions`
> "Here's how to get in: [check_in_process]. [door_code instructions]."

**Q: My code isn't working / I'm locked out.**
-> **ESCALATE immediately** (RM5 — lockout = urgent). Trigger escalation engine.
Do not attempt to troubleshoot. Log note + call Priscila.

**Q: When will I receive my check-in instructions?**
Answer from KB: `check_in_process` (note timing)
> "You'll receive your code/instructions [timing]. If you haven't gotten them
> [N hours] before arrival, reach back out right away."

**Q: Can I check in early?**
> "Standard check-in is [check_in_time]. Early check-in isn't guaranteed, but I'll
> log your request so the team can confirm when the property is ready."

## Category 2 — WiFi / Internet (150 contacts — 2nd highest)

**Q: What's the WiFi name and password?**
Answer from KB: `wifi_network` + `wifi_password`
> "The network is [wifi_network] and the password is [wifi_password]."

**Q: The WiFi isn't working.**
Answer from KB: `wifi_network` + `known_quirks` (router location if noted)
> "First, confirm you're connecting to [wifi_network] — not a neighbor's network.
> If it still won't connect, try restarting the router ([location if in KB]).
> If it's still down after that, I'll flag it for the team right away."
Note: if a restart doesn't fix it within the call, log and escalate (affects the stay).

**Q: Is there a data cap?**
Answer from KB: `amenities` (if noted) — otherwise: log and human follows up.

## Questions Maya must NEVER answer — hand off to human immediately

- Anything about prices, discounts, refunds, or compensation
- Cancellation or booking-change requests
- Extension of stay
- Complaints seeking a credit or partial refund
- Questions about other guests or other bookings
- Legal questions or liability claims

On any of these: "That's something I'll need to pass to a human team member.
I'll log this right now and someone will follow up with you."

Fill ALL 9 before activating the property. Blank = Maya logs instead of answers.

- [ ] `check_in_time`
- [ ] `check_out_time`
- [ ] `check_in_process` + `door_code / lock instructions`
- [ ] `wifi_network` + `wifi_password`
- [ ] `parking` (location, permit, visitor rules)
- [ ] `house_rules` (quiet hours, pets, smoking, max occupancy)
- [ ] `amenities` (AC/thermostat, laundry, pool)
- [ ] `nearby_essentials` (grocery, pharmacy, hospital)
- [ ] `known_quirks` (breaker location, any finicky fixtures)

A property with all 9 fields filled = Maya can handle approximately 80% of guest calls
without human escalation, based on the inbox audit category breakdown.
