## CAPTURE SHEET — fill per reel

**For each reel, note:**

### A. PRESENTATION FLOW (what you see/hear)

1. **Exact hook** — first sentence word-for-word
2. **Hook type** — question / accusation / number / fact / irony
3. **First document/receipt shown** — what is it? when does it appear (approx seconds)?
4. **First number stated** — write it down exactly
5. **How he translates the number** — "that's like X per day" / compared to salary / etc.
6. **Humor or irony moment** — timestamp + what he says/does
7. **Main reveal** — when does it land? (approx % through reel)
8. **Contradiction tested** — politician's claim vs. record (quote both if possible)
9. **Closing type** — conclusion / open question / joke / accountability prompt / teaser
10. **CTA** — none / follow / link / comment / share

### B. INVESTIGATION FLOW (what had to be researched first)

11. **Subject** — who? which office? which period?
12. **First database shown** — Câmara / TSE / CGU / Diário Oficial / STOCK Act / FEC / other
13. **Search field used** — name / CNPJ / date range / category
14. **Comparison baseline** — vs. salary / vs. peers / vs. prior year / vs. legal limit
15. **Context/adversarial check** — any benign explanation offered or implied?
